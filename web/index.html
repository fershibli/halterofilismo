Halterofilismo

Jogo de levantamento de peso para dois jogadores em rede, feito em 2014 para a matéria de Redes: quem apertar A W D S nessa ordem mais rápido levanta a barra primeiro. O original mandava o "poder de luta" de cada um por UDP; aqui o código Python original roda via Pyodide e as mensagens vão por WebRTC.

As portas que o jogo pede não importam mais (digite quaisquer números). Um jogador escolhe 2 (Esperar) e passa o código da sala que o jogo mostra como "Seu IP"; o outro escolhe 1 (Se conectar) e digita esse código quando o jogo pedir o IP do amigo. H e depois Q sai.

C:\Python27\python.exe halterofilismo.py
